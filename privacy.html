Kebijakan Privasi — JARVIS Bali

Terakhir diperbarui: 1 Oktober 2026

JARVIS Bali adalah panduan AI untuk wisata Bali. Aplikasi ini tidak berisi iklan, tidak menjual data, dan tidak membuat profil pengguna untuk pelacakan. Aplikasi ini memakai kunci API milik Anda sendiri (BYOK): Anda memasukkan kunci Gemini Anda sendiri di menu Pengaturan, dan kunci tersebut disimpan hanya di perangkat Anda.

2. Tujuan dan pihak ketiga

Data yang keluar perangkat hanya dikirim ke penyedia berikut, dan hanya sebatas yang dibutuhkan fitur:

  • Google Gemini API — suara, gambar, teks, dan konteks lokasi untuk menghasilkan jawaban.
  • Penyedia ubin peta — koordinat peta yang sedang Anda lihat, untuk menggambar peta.
  • OSRM (router publik) — titik awal dan tujuan untuk menghitung jarak dan waktu rute.
  • Open-Meteo — koordinat untuk data cuaca.
  • exchangerate-api — nilai tukar untuk konversi harga.
  • Server memori JARVIS (opsional) — hanya bila Anda mengaktifkan "Simpan memori di server". Bila dimatikan, preferensi dan catatan perjalanan tetap berada di perangkat dan hilang saat aplikasi ditutup.
Mode lokasi "Setara area". Aplikasi menyediakan mode yang membulatkan koordinat sekitar 1,1 km sebelum dikirim ke penyedia peta, rute, dan cuaca. Mode ini mengurangi jejjak perjalanan dan tetap membuat peta, rute, dan cuaca berfungsi normal.

3. Penyimpanan dan retensi

  • Preferensi, kunci API, histori obrolan, dan lokasi disimpan di penyimpanan lokal perangkat (WebView localStorage dan SharedPreferences).
  • Data tidak disimpan di server kami, kecuali memori cloud bila Anda mengaktifkannya.
  • Data hilang permanen saat aplikasi di-uninstall atau saat Anda memilih "Hapus semua data" di menu Pengaturan.
  • Cache WebView dibersihkan otomatis setiap kali versi aplikasi diperbarui.

4. Hak Anda

  • Menarik izin Mikrofon, Kamera, dan Lokasi kapan saja lewat Setelan Android.
  • Menghapus seluruh data lokal kapan saja lewat Pengaturan → Data & privasi → Hapus semua data.
  • Menghapus histori obrolan dan memori sesi kapan saja dari aplikasi.
  • Mematikan memori cloud kapan saja.

5. Penggunaan oleh anak

Aplikasi ini ditujukan untuk pengguna umum, bukan anak di bawah umur, dan tidak mengumpulkan data dengan sengaja dari anak.

6. Perubahan kebijakan

Perubahan material pada kebijakan ini akan disertakan dalam pembaruan aplikasi, dan tanggal "terakhir diperbarui" di atas akan ikut diperbarui.

English summary

JARVIS Bali processes microphone audio (live voice), camera images (vision mode), location (GPS LIVE, routing, and weather), and chat text in order to answer you. Audio, images, text, and location context are sent to the Google Gemini API using your own API key. Map tiles, routing (OSRM), weather (Open-Meteo), and currency rates are fetched from their public providers, using only the coordinates needed for the feature you are using. Optional cloud memory is off by default and stores nothing on our servers when disabled. Preferences, API key, and chat history live only on your device and are deleted on uninstall or via Settings → Data & privacy → Erase all data. No ads, no sale of data, no tracking profiles.
